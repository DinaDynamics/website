Interactive Three.js experiments exploring Dina Dynamics' visual identity: metallic surfaces, real glitter shaders, and cinematic 3D rendering.

Experiments

Material Playground

Interactive 3D sphere with real-time material editing. Test glitter properties, metallic finishes, lighting, and bloom effects. Switch between 5 color palettes and 5 material presets.

Hero A: Liquid Metal

Responsive morphing mesh that deforms based on cursor movement. Demonstrates PBR metallic materials with realistic reflections. Minimal text overlay on immersive 3D geometry.

Launch Experiment →

Hero B: Glitter Field

Particle parallax system with 1500+ instances. Each particle responds to cursor movement with individual physics. Dense glitter material with responsive lighting and parallax depth.

Hero C: Dimensional Type

3D "DINA DYNAMICS" typography using real FontLoader and TextGeometry. Beveled letters with glitter shader applied. Professional 3D hero text as primary visual element.

Technology Stack

Three.js r170

WebGL rendering engine with modern ES modules and advanced materials.

GLSL Shaders

Custom fragment shaders for real glitter using Worley noise patterns.

MeshPhysicalMaterial

PBR material with clearcoat, metalness, and roughness controls.

PMREMGenerator

Environment mapping for realistic reflections on metallic surfaces.

UnrealBloomPass

Post-processing glow effect for highlights and glitter sparkles.

lil-gui

Live material and animation parameter controls in browser.

OrbitControls

Mouse-based 3D camera control with damping and auto-rotation.

FontLoader & TextGeometry

Real 3D typography with bevels and material mapping.

Local Development

Start the development server: python3 -m http.server 8000
Open in browser: Navigate to http://localhost:8000/design-playground/
5 Color Palettes: Electric Cobalt (default), Imperial Sapphire, Arctic Steel, Deep Atlantic, Midnight Titanium. Switch palettes globally from any experiment.
Material Presets: Silver Chunky, Silver Fine, Silver Mixed, Cobalt Glitter, Polished Metal. Each preset includes optimized glitter parameters and material properties.
Export Settings: Use the "Export as JSON" button in Material Playground to save and load custom material configurations.
