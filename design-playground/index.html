How to Use This Playground

Material Playground: Drop-down menus to switch between glitter presets and color palettes. Watch the 3D sphere update in real-time with different material properties.

Hero Concepts: Each hero is a full-screen immersive experience. Move your mouse to interact with the visuals. Use the theme switcher (top right) to preview all five color palettes.

Development Focus: These experiments showcase procedural glitter, metallic reflections, responsive lighting, and cursor-driven interactivity. All materials use realistic PBR (Physically Based Rendering) principles.

Theme System

All experiments support five interchangeable color palettes with metallic silver (#C0C0C0) as the constant primary color across all themes:
